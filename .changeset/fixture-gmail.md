Initial release of the Gmail fixture package. Provides the `gmail` fixture and `useGmail` factory — find (`findEmail` with string/RegExp filters), read (`readEmail`) and send (`sendEmail`) emails via the Gmail API straight from tests, plus string HTML body primitives (`h1`–`h6`, `table`, `div`, `img`, ...) shared with `reporter-email`.
